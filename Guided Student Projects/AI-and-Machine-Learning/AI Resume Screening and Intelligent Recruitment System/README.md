# 🤖 AI Resume Screening and Intelligent Recruitment System

## 📌 Project Overview

The **AI Resume Screening and Intelligent Recruitment System** is a web-based recruitment platform designed to automate resume analysis, candidate-job matching, ranking, and interview management.

The system uses **TF-IDF and cosine similarity** to evaluate the relevance between resumes and job descriptions. It also supports skill-based matching, resume anonymization, automated candidate ranking, and role-based recruitment workflows.

## 🎯 Objectives

- To automate resume screening and candidate evaluation.
- To match resumes with relevant job descriptions.
- To reduce manual effort in recruitment.
- To rank candidates based on job relevance.
- To support skill-based candidate evaluation.
- To reduce potential recruitment bias through resume anonymization.
- To provide integrated interview management.
- To provide separate workflows for applicants and recruiters.

## ⚙️ Key Features

- 📄 Automated resume parsing
- 🤖 AI-based resume-job matching
- 📊 TF-IDF text vectorization
- 🔍 Cosine similarity analysis
- 🧠 Skill-based matching
- 🏆 Automated candidate ranking
- 👤 Applicant management
- 💼 Recruiter dashboard
- 🕵️ Resume anonymization
- 📅 Interview scheduling
- 📝 Interview question management
- 🔐 Role-based access control
- 📑 PDF report generation
- 🔔 Application status notifications
