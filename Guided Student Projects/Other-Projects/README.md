# 📚 Other Projects

This section contains student projects that **do not clearly fall within the primary project categories** maintained in this portfolio.

The category provides flexibility for documenting multidisciplinary, specialized, experimental, hardware-oriented, or otherwise unique projects undertaken under my academic guidance.

---

## 🎯 Purpose

Projects may be placed here when their primary focus does not appropriately correspond to:

- Software & Web Applications
- Cloud & Distributed Systems
- Artificial Intelligence & Machine Learning
- Cybersecurity
- Database & Information Systems

Projects will be categorized based on their **actual primary objective and implementation**, rather than being forced into an unrelated technical category.

---

## 🧑‍🏫 Project Guidance

My role as project guide may include:

- Project topic selection
- Problem identification
- Requirement analysis
- Technical guidance
- Solution design
- Implementation support
- Testing and validation
- Documentation review
- Presentation and viva preparation
